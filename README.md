# 🏠 Home Layout AI

This app generates 2D home layout designs using AI (Mistral-7B) and Streamlit, with smart caching to reuse similar layouts.

## Features
- Streamlit UI
- Hugging Face Inference API (Mistral)
- JSON layout generator
- Plotly 2D layout visualizer
- Local caching to save token usage

## Setup

```bash
pip install -r requirements.txt
streamlit run app.py
